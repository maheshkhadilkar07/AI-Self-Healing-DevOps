Project

AI Self Healing DevOps — Lokmanya Tilak Jankalyan Shikshan Sanstha's Priyadarshini College of Engineering, Nagpur (Autonomous, affiliated to R.T.M. Nagpur University)

Abstract

Problem. Manual detection and recovery of cloud application failures leads to high downtime and MTTR.

Solution. An AI-powered self-healing DevOps system that continuously monitors applications, detects anomalies, identifies root causes, and automatically performs safe recovery actions to minimise downtime and MTTR.

Architecture. A 5-layer stack: MERN application, Docker/Kubernetes, AI-based anomaly detection and RCA, automated remediation with policy validation, and health verification with continuous learning.

Security. RBAC, secure API communication, secrets management, container security, AI action validation, audit logging, and human approval for high-risk remediation.

Outcome. Reduced downtime and MTTR, faster failure detection and recovery, minimised human intervention, improved reliability, and safer automated DevOps operations.

Introduction

Problem statement. Manual detection, diagnosis and recovery of cloud application failures lead to increased downtime, high MTTR and dependency on DevOps engineers.

Proposed solution. An AI-powered self-healing DevOps system that automatically detects anomalies, identifies root causes, performs safe remediation and verifies recovery with minimal human intervention.

Key features

  • AI-based anomaly detection — unusual behaviour from real-time metrics and logs (AI Lab)
  • Automated root cause analysis — telemetry and historical incidents (dependency graph)
  • Self-healing and safe remediation — restart, scaling, rollback (policy)
  • Recovery verification and learning — health checks, knowledge base (incidents)

Objectives

  • Reduce downtime and Mean Time To Recovery (MTTR)
  • Detect failures faster than manual monitoring
  • Minimise human intervention for routine failures
  • Keep automation safe through policy checks, verification and human approval
  • Learn from every incident to improve future responses

Conclusion

AI-powered self-healing DevOps enables automated detection, diagnosis and recovery from cloud application failures. Integrating AI/ML, observability, root cause analysis and automated remediation reduces manual intervention and downtime. Policy-based security and recovery verification ensure that automated actions are safe and effective. The framework can improve reliability, availability and MTTR while providing a foundation for autonomous DevOps operations.
